# 滑雪俱乐部小程序（ski-club）

俱乐部会员报名与拼团活动的原生微信小程序。访客可直接浏览各模块内容概览，注册会员经管理员审核通过后可查看详细信息、发布内容与报名参团。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 滑雪搭子 | 拼车 / 拼搭子发布与报名，报名人员信息按权限分级展示 |
| 俱乐部参团 | 管理员发布活动与多档价格，会员在线报名、提交付款信息，管理员确认收款并导出单活动名单 |
| 教练平台 | 认证教练主页、可约时段与学员预约 |
| 二手交易 | 装备闲置发布与浏览 |
| 我的 | 会员资料、我的发布与订单、审核状态、管理入口 |

## 权限层级

- `member` 注册会员 / `coach` 认证教练 / `admin` 管理员 / `super_admin` 高级管理员
- 高级管理员全局唯一（数据库部分唯一索引保证），拥有最高权限
- 高级管理员档案对其他任何用户不可见（含其他管理员），仅本人可查看与修改
- 内容发布后经管理员审核通过才对外展示；访客仅能看到已审核内容

## 技术栈

- 原生微信小程序（WXML / WXSS / JS），无构建步骤
- 云端：WorkBuddy 云数据库（PostgreSQL + RLS + 安全视图），通过 `@tencent-ai/workbuddy-cloud-sdk` 访问
- 权限在数据库层用 RLS 策略与 `SECURITY DEFINER` 函数实现，前端只做展示适配

## 目录结构

```
app.js / app.json / app.wxss   小程序入口、页面与全局样式
pages/                         19 个页面
components/                    access-gate（访问门禁）、avatar-picker（头像选择）
utils/                         云访问、权限守卫、校验、导出、UI 文案等公共模块
assets/                        图标与图片资源
tools/                         单测、结构校验、数据处理脚本（非运行时代码）
```

## 本地运行

1. 用微信开发者工具「导入项目」，目录选择本仓库根目录
2. `appid` 默认为 `touristappid`（测试号），正式发布需替换为自己的小程序 AppID
3. 依赖安装：`npm install`（仅云端 SDK 与测试脚本需要）

## 自检

```bash
npm install
node tools/unit-test.js     # 单元测试与断言
python tools/validate.py    # 页面 / JSON / 结构校验
```

## 说明

- `utils/cloud.js` 中的 `publishableKey` 是云端**可发布公钥**，设计上用于客户端，不具管理权限；真正的数据边界由数据库 RLS 与安全视图控制。
- 会员实名资料（姓名、身份证号、手机号）仅在受控视图中按权限投影，普通会员看不到他人完整档案。
